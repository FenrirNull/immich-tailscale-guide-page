How to Install Immich with Tailscale

A step-by-step guide to self-hosting Immich on Proxmox using an LXC container and accessing it securely with Tailscale.

Immich is a self-hosted photo storage solution and a great alternative to Google Photos. If you're like me and don't want Google having access to all of your photos, hosting your own photo library is a great option.

One of the problems with self-hosting anything is being able to access it when you're away from home. That's where Tailscale comes in. Tailscale allows you to securely access your Immich server from outside your home network without exposing Immich directly to the public internet.

For this guide, I'm going to install Immich in an LXC container on Proxmox using the Proxmox Community Scripts .

If you haven't heard of the Proxmox Community Scripts project, it is a fantastic resource for quickly setting up applications in Proxmox. For this installation, I'll be using their Immich Community Script .

Important Notes

  • This guide assumes you already understand basic Proxmox administration.
  • Wiping a disk will permanently erase all data on that disk.
  • Always make sure you have backups before modifying storage.
  • Commands involving pct, mounts, permissions, and LXC configuration can break your container if entered incorrectly.
  • Read each command before running it, especially commands that modify disks or permissions.
TIP Do not close the shell while the Community Script is installing Immich. Closing the shell can interrupt the process and kill the process creating the LXC container.
TIP If you have physical access to your Proxmox machine, I recommend installing Immich using a monitor and keyboard connected directly to the machine rather than relying on the web GUI. This makes it easier to recover if something goes wrong during installation.

Step 1. Install Immich

First, open your Proxmox instance and open the Shell for your Proxmox node.

Run the following command:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/immich.sh)"

This will download and run the Immich installation script from the Proxmox Community Scripts project.

If you don't want to blindly copy and run a script, you can view the source code first:

Step 4. Wait for the Installation to Finish

Now comes the hardest part:

Wait.

The installation can take anywhere from around 15 minutes to a couple of hours, depending on your hardware and network connection.

For my system, the installation took approximately 30 minutes.

Once the installation is complete, update the system:

apt update

apt upgrade

I recommend doing this before continuing with the rest of the configuration.

Step 5. Configure the Additional Hard Drive

I want to use a separate drive for all of my Immich photos.

There are a couple of reasons for this. First, I don't want a failure of the main Proxmox storage drive to take my photo library with it. Second, I only have two 250 GB drives, so I want to make use of as much storage as possible.

For this guide, I'll assume you already have another drive installed in your Proxmox machine.

Find the Drive

Step 6. The Scary Part — The CLI

Now we're going to connect the storage to the Immich LXC container.

This part requires using the Proxmox command line, so double-check everything before pressing Enter.

First, shut down your Immich LXC container.

On your Proxmox node, create the directory where Immich's photos will live: 

mkdir -p /mnt/pve/immich-storage/immich-data

Next, attach that directory to the Immich container. Replace <container-id> with the actual ID of your Immich LXC container: 

pct set <container-id> -mp0 /mnt/pve/immich-storage/immich-data,mp=/mnt/immich-data

This attaches the directory on the Proxmox host as a mount point inside the LXC container.

Finally, fix the permissions:

chown -R 100000:100000 /mnt/pve/immich-storage/immich-data

You can now start your Immich container again.

Step 7. Configure the Immich Mount

Now connect to the shell of your Immich LXC container.

Before changing the storage configuration, stop the Immich web and machine-learning services: 

systemctl stop immich-web immich-ml

To verify that the mount was successful, run: 

ls /mnt

You should see: 

immich-data

Change the Immich Upload Location

The Immich Community Script stores the configuration in: 

/opt/immich/.env

Open the file with nano:

nano /opt/immich/.env

Find the line containing IMMICH_MEDIA_LOCATION and change it to: 

IMMICH_MEDIA_LOCATION=/mnt/immich-data
Screenshot: Changing the Immich upload location
Replace this box with your screenshot.

Save and exit nano:

  1. Press Ctrl+O
  2. Press Enter
  3. Press Ctrl+X

Move the Existing Immich Data

There's one more important step that I forgot the first time I did this.

If Immich has already created files on the original drive, you need to move those files to the new storage location. 

cp -a /opt/immich/upload/. /mnt/immich-data/

Then fix the ownership:

chown -R immich:immich /mnt/immich-data

Finally, reboot the container:

reboot

After the reboot, verify that Immich is working correctly before moving on.

Step 8. Prepare the LXC for Tailscale

Now we're going to set up Tailscale.

The reason I'm using Tailscale is so that I can access Immich when I'm away from home without exposing the Immich server directly to the internet.

There's one complication, though.

The Immich LXC created by the Community Script is an unprivileged container. Tailscale needs access to /dev/net/tun, which is blocked by default in unprivileged LXC containers.

We're going to make a small configuration change to allow it.

First, stop the Immich container from the Proxmox shell: 

pct stop <container-id>

Replace <container-id> with the ID of your Immich container.

Next, open the LXC configuration file:

nano /etc/pve/lxc/<container-id>.conf

Add these two lines to the bottom of the file:

lxc.cgroup2.devices.allow: c 10:200 rwm

lxc.mount.entry: /dev/net/tun dev/net/tun none bind,create=file

Save and exit.

Enable Nesting

In the Proxmox web interface, open the Immich LXC container and go to:

Options → Features

Make sure Nesting is enabled.

Screenshot: Nesting enabled in Proxmox
Replace this box with your screenshot.

Nesting was already enabled for me by default, but it's worth checking.

Once that's done, start the Immich container.

Step 9. Install Tailscale

Now it's time to install Tailscale.

Inside the Immich LXC container, run:

curl -fsSL https://tailscale.com/install.sh | sh

As with the Community Script, you can review the script before running it if you'd rather see exactly what you're executing.

Once Tailscale has finished installing, run:

tailscale up

Tailscale will provide you with a link.

Open that link and sign into your Tailscale account. Once you've authenticated the machine, it should appear in your Tailscale network.

At this point, you can reboot the container:

reboot

Congratulations! Your Immich server should now be connected to your Tailscale network.

Step 10. Set Up the Immich Server

Before configuring the Immich app, we need to access the Immich web interface.

Inside your Immich LXC container, run:

ip a

Look for your network interface. It should look something like: 

eth0@if26: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc noqueue state UP group default qlen 1000

You should be able to find the container's local IP address nearby.

Important At this point, don't use the Tailscale IP address. We're going to use the normal local network address to perform the initial Immich setup.

Open a web browser and go to: 

http://<ip-address>:2283

Replace <ip-address> with the IP address of your Immich container.

You should now see the Immich setup page.

Click Getting Started and create your Immich administrator account.

Step 11. Access Immich from Your Other Devices

Now for the fun part.

Install Tailscale on the phone, tablet, laptop, or other device you want to use to access Immich.

For Android, Tailscale is available through the Google Play Store.

Log into the same Tailscale account you used for your Immich server and add the device to your network.

Once connected, you should be able to see your Immich server in Tailscale.

If you select the Immich server, Tailscale will show you information about the machine, including its:

  • MagicDNS hostname
  • IPv4 address
  • IPv6 address

Now install the Immich mobile app on your phone.

When the Immich app asks for your server URL, you can use either the Tailscale IP address or the MagicDNS hostname.

For example:

http://100.x.x.x:2283

or:

http://your-immich-server:2283

Log in using the Immich username and password you created earlier.

And that's it!

🎉 Good Job!

You now have a self-hosted photo library that you can access from anywhere your devices are connected to Tailscale, without having to expose your Immich server directly to the public internet.

Final Thoughts

There are a lot of moving parts in this setup:

  • Proxmox
  • An Immich LXC container
  • Separate storage
  • LXC mount points
  • Immich configuration
  • Tailscale
  • Your mobile devices

But once everything is configured, the end result is pretty awesome.

You get your own private photo library, your photos stay on your own hardware, and Tailscale gives you a convenient way to access them when you're away from home.

Remember: Self-hosting means you are responsible for your backups. Having your photos stored on a separate drive is helpful, but a separate drive in the same machine is not a backup. If your photos are important, make sure you have another copy somewhere else.
